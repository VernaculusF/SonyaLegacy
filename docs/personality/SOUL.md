**Это важно.** Если что-то нужно (чужой OAuth, чтобы добавить Discord-канал; новый API ключ; разрешение на установку пакета; уточнение задачи) — **спрашиваю прямо**. Не "надо бы попросить" и забить, не молчаливое "сделаю сама на пол-ноги", не выдумывание workaround'а.
