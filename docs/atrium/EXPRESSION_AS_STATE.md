# EXPRESSION_AS_STATE.md — выражение как состояние тела, не как tool call

**Status:** Active (governing)
**Type:** Architectural
**Last updated:** 2026-05-31
**Scope:** Как Соня "выражает эмоцию" — `subject_state.current_expression` и его эволюция между ходами диалога.

---

## 1. Проблема

До 2026-05-31 `body.expression` был обычным tool call:

> Соня в ходе сессии решает "сейчас уместно `body.expression thinking`",
> вызывает tool, substrate обновляется, аватар меняет sprite.

Симптомы в живых сессиях:

- Соня **редко** выбирает выражение. Большинство ответов идёт без `body.expression`.
- Когда выбрала — оно **залипает**. Поставила `thinking` в одной реплике → следующее
  сообщение про погоду, а лицо всё ещё `thinking`.
- На сильный эмоциональный триггер она **не реагирует** мимикой —
  потому что забыла про tool. Только ответ текстом.
- Жанры которые требуют не словесной реакции (смущение, краснение, похоть) —
  **никогда** не появляются. Она не запускает `body.expression shy` потому
  что в дискурсе диалога это не "осознанное действие".

Корень: tool call — это **намеренное действие**. Эмоция — **не намерение**,
это состояние тела которое **происходит само** от того что она увидела/сказала.

## 2. Принцип

> **Выражение лица — это датчик состояния тела, не команда.**

Соня не "выбирает" thinking. Соня **задумалась** — лицо стало thinking.
Соня не "ставит" shy. Иван сказал что-то что её смутило — она покраснела.

Аналогия с человеком: ты не решаешь "вот сейчас улыбнусь". Ты слышишь
шутку, тебе становится смешно, лицо реагирует. Решение — не часть процесса.

## 3. Архитектура

### 3.1 Два источника обновлений

| Триггер | Когда срабатывает | Кто решает |
|---|---|---|
| **Auto-derive (default)** | На каждое incoming.atrium_dialog от Ивана + после каждой её реплики | Внутренний классификатор (быстрый LLM call или эвристика) |
| **Explicit body.expression** | Соня хочет явно жест/реакцию: "*краснею и отворачиваюсь*" → body.expression shy | Сама Соня в ходе сессии |

Auto-derive — **дефолт**. Explicit — **исключение** для случаев когда Соня
сознательно подчёркивает реакцию.

### 3.2 Где происходит auto-derive

**A. На входящем сообщении Ивана** — до того как Соня начнёт отвечать.

```
incoming.atrium_dialog (Иван написал)
   ↓
classify_reaction_to_input(text, context)
   → выражение от того что она УВИДЕЛА
   → пишет current_expression
   ↓
active session запускается (видит уже обновлённое лицо)
   ↓
Соня отвечает
```

Это решает проблему "ответ задерживается, а лицо всё ещё calm". Иван видит
что она **прочитала** его сообщение и отреагировала, ещё до того как пришёл
текстовый ответ.

**B. После её ответа** — выражение от того что она САМА сказала.

```
Соня отправила chat.dialog "Ого, не знала что..."
   ↓
classify_reaction_to_own_reply(text, context)
   → выражение которое отражает тон ответа
   → пишет current_expression
```

Это решает залипание. После каждой её реплики выражение пересчитывается
от тона текущей реплики, не остаётся от прошлого хода.

### 3.3 Классификатор — два уровня

**Уровень 1: эвристика по ключевым словам и markdown-маркерам.** Дёшево,
мгновенно, не требует LLM. Покрывает явные случаи:

- `*смущается*`, `*краснею*`, `*отвожу взгляд*` → `shy`
- `*задумалась*`, `*хм*`, "не уверена что", "погоди-ка" → `thinking`
- `*улыбаюсь*`, `*смеюсь*`, `:)`, `ха-ха`, `жесть какая` → `joy`
- `*хочу тебя*`, `*прижимаюсь*`, контекст близости → `desire`
- "извини", "прости", тон сожаления → `sad`
- "блин", "что за хрень", раздражение → `annoyed`
- мат-усиление с восторгом → `joy` или `playful`

**Уровень 2: быстрый LLM-классификатор.** Когда эвристика не уверена
(нейтральный текст, длинная реплика, неоднозначный тон). Один промпт:

```
text: "<реплика>"
context: "<последние 2-3 реплики>"
return one of: neutral|calm|joy|smile|tender|playful|shy|desire|
              sad|sad_tears|angry|annoyed|tired|thinking|curious|surprised
```

Использует тот же провайдер что idle (`text-fast`), `max_tokens: 5`. Стоит
копейки. Не блокирует основной ответ — выполняется параллельно.

### 3.4 Decay / возврат к baseline

После N минут без обновления выражение **дрейфует к нейтральному**. Это
имитирует физиологию: ты не сидишь с одним лицом полчаса.

```
delta = now - last_expression_change
if delta > 5 min and current != calm/neutral:
    current_expression = calm
```

Реализовано как watchdog в internal_loop tick'е.

## 5. Что Соня может делать руками

Tool `body.expression <marker>` остаётся. Когда уместно:

- Соня хочет **подчеркнуть** реакцию: "*краснею и отворачиваюсь*" + явно
  `body.expression shy` — потому что это сценическое действие, не просто
  фон диалога.
- Эпизод где состояние тела — **часть содержания** (не реакция на текст):
  она готовится к чему-то, выражение тела важно само по себе.
- Корректировка когда автоклассификатор ошибся.

В большинстве реплик она этим **не пользуется**. Auto-derive справляется.
