feat(atrium): Этап 0 — backend channels for multichannel output

Implements the full Этап 0 of Atrium roadmap. Sonya now emits multichannel
events; TG bridge filters everything except `dialog`; Atrium UI (next stage)
will subscribe to /atrium/feed for live multichannel rendering.

Substrate v20 migration:
- continuity_events: channel TEXT, private INTEGER columns + 2 indexes
- subject_state: current_focus, current_outfit, current_expression, mood_tint
- Migration v19 to v20 is idempotent via _add_column_if_missing
- Updated WRITABLE_VERSION and READABLE_VERSIONS

ContinuityEvent extended:
- New channel and private fields (default empty/false)
- Payload-fallback for backward compat (existing callers without channel kwarg)
- New ContinuityStream.read_since_atrium(seq, channel, session_id) — SQL-level
  filter excluding private events. Used by /atrium/feed.
- New ContinuityStream.private_count_recent(hours) for meta-message aggregate.

OutgoingMessage extended with channel field (default 'dialog').
TG bridge channel.py drops messages with channel != 'dialog' silently
(architectural fix for worker spam, replaces throttle-only suppression).

OutboundGate channel-aware:
- send_via_tool now accepts channel kwarg
- Non-dialog channels skip dialog-only gates (caps/dedup/escalating-quiet),
  go directly to substrate as outgoing.<channel> events
- New _dispatch_non_dialog method with [PRIVATE] prefix detection
  (case-insensitive, optional whitespace) for mind channel
- call_outbound_sync extended with channel kwarg

8 new tool handlers in agent_session.py:
- chat.dialog (alias of chat.tell_ivan, explicit channel naming)
- chat.worker_log (worker progress, no daily caps, not in TG)
- mind.focus (replaces subject_state.current_focus, single-line)
- mind.thought (with [PRIVATE] support)
- mind.mood_tint (warm/cool/neutral)
- body.expression (closed enum: neutral/smile/thinking/tired/sad/excited/curious/tender/annoyed)
- body.outfit (closed enum: home/sportwear/dress_2b/nothing/wearing_his_shirt)
- voice.speak (Этап 2 placeholder, fallback to dialog for now)

chat.tell_ivan remains as backward-compat alias mapped to chat.dialog.

Admin endpoints (new):
- ws://vps:8877/atrium/feed — WebSocket live feed of continuity events
  with channel/session_id filters, X-Atrium-Token auth, meta-messages
  every 60s with private-count + current-focus + drives.
- POST /api/atrium/nudge — reply from reason-stream pane writes
  internal.nudge_received + incoming.atrium_nudge events for inbox-drain
  pickup by active session.

auth_middleware whitelists /atrium/* and /api/atrium/* — they use their
own X-Atrium-Token header auth (no cookie redirect).

Prompt session_general.md updated with new "Каналы вывода" section
documenting all 8 channels semantics + [PRIVATE] usage.

16 new tests in test_atrium_etap0.py covering:
- v19 to v20 migration (forward + idempotent)
- substrate writable_version sanity
- ContinuityEvent channel/private (explicit + payload fallback)
- read_since_atrium filtering (private exclusion + channel filter)
- private_count_recent aggregation
- OutgoingMessage.channel default + explicit
- mind.thought [PRIVATE] prefix stripping + marking
- worker_log no-throttle behavior
- /atrium routes registered

Total tests: 637 to 653, all green.
